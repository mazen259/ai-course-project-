# BFS — النسخة المبسطة

المشروع ينفّذ BFS فقط على الجراف الموجّه في المثال المحلول. تكلفة كل وصلة 1.

## الملفات

- `bfs.py`: الخوارزمية وحفظ خطواتها، حوالي 40 سطرًا.
- `app.py`: واجهة Streamlit وصياغة المسألة والرسم والأنيميشن.
- `requirements.txt`: المكتبة المطلوبة.
- [الشرح وأسئلة المناقشة PDF](BFS_Problem_Formulation.pdf).
- [تحميل المشروع ZIP](BFS_Search_Lab.zip).

## التشغيل

استخدم Python 3.11 أو أحدث، ثم افتح الطرفية داخل مجلد المشروع:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

اختر البداية والهدف. شريط الخطوات يعرض لقطة واحدة، وزر التشغيل يعرض البحث كاملًا من البداية إلى النهاية. لتعديل الجراف عدّل القاموس `graph` في أول `app.py`. يجب أن يكون لكل جار مفتاح في القاموس، والحالة الطرفية قائمتها فارغة.

## اشرح الكود بهذا الترتيب

1. `queue`: تحفظ الحالات التي تنتظر الفحص. `popleft()` تنفّذ FIFO.
2. `visited`: حالات اكتشفناها، وتشمل الحالات التي ما زالت داخل الطابور. نسجّل الحالة عند إضافتها لمنع تكرارها والدورات.
3. `parent`: أب كل حالة؛ نستخدمه لاستخراج المسار، ثم نعكس القائمة.
4. `order`: الحالات التي خرجت من الطابور بالترتيب.
5. `steps`: نسخ من حالة البحث للرسم فقط. `bfs` تعيد المسار والخطوات، و`show_step` ترسم لقطة.

المثال: ترتيب الزيارة `A B C E F G D H`، والحل `A C F H`، والتكلفة 3. ترتيب الزيارة ليس مسار الحل.

## صياغة المسألة

الحالة اسم عقدة. البداية A، والهدف H. الحركة انتقال إلى جار مباشر، ونموذج الانتقال يعيد الجار المختار. اختبار الهدف مقارنة الحالة بـH. تكلفة المسار عدد الوصلات لأن كل وصلة تكلفتها 1. الواجهة تعرض الصياغة حسب البداية والهدف المختارين.

## أسئلة مناقشة سريعة

- **لماذا BFS؟** تبحث مستوى بمستوى وتجد أقل عدد وصلات.
- **هل هي دائمًا أقل تكلفة؟** عند تساوي تكاليف الوصلات، كما هنا. اختلاف الأوزان يلغي هذا الضمان.
- **هل تتوقف مع الدورات؟** نعم، لأن `visited` تمنع إضافة الحالة مرتين.
- **لو البداية هي الهدف؟** مسار من حالة واحدة وتكلفة صفر.
- **لو الهدف غير متاح؟** يفرغ الطابور وترجع قائمة مسار فارغة.
- **Time وSpace؟** البحث الأساسي O(V + E) وقت وO(V) ذاكرة إضافية. نسخ الخطوات وبناء المسارات للعرض قد يضيف O(V²) وقتًا وذاكرة؛ ليست هذه تكلفة BFS الأساسية.
- **وصيغة السكشن O(b^d)؟** تحليل لشجرة البحث، حيث b التفرع وd عمق أقرب هدف. فحص الهدف بعد إخراجه قد يولّد بعض المستوى d+1، فيكون الحد المحافظ O(b^(d+1)).
